# Cloud-Native E-Commerce Platform

A cloud-native e-commerce backend built with FastAPI, developed as a Cloud Computing & DevOps mini project. The API is deliberately simple. The focus is on deploying and operating it with Docker, Azure, Terraform and GitHub Actions.

## Progress

- **Week 1: FastAPI REST API.** Product CRUD endpoints with request validation and Swagger docs.
- **Week 2 (in progress):** Project restructure, environment-based configuration, `/health` endpoint and test suite done. PostgreSQL persistence is next.

Product data is currently stored **in memory**, so it resets whenever the application restarts.

## Technology

- Python 3.11+
- FastAPI and Uvicorn
- Pydantic and pydantic-settings
- pytest

## Project structure

```text
app/
├── main.py                 # Creates the FastAPI app and registers routers
├── core/config.py          # Settings loaded from environment variables
├── routers/health.py       # GET / and GET /health
├── routers/products.py     # Product REST endpoints and temporary data
└── schemas/product.py      # Pydantic request and response schemas
tests/
├── conftest.py             # Shared test setup and fixtures
├── test_health.py
└── test_products.py
.env.example                # Template for local environment variables
```

`ProductBase` holds the validation rules shared by `ProductCreate` (new products) and `ProductUpdate` (the full replacement data sent to `PUT /products/{id}`). `ProductResponse` adds the ID generated by the application.

## Setup

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it in Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Or on macOS/Linux:

```bash
source .venv/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Create your local environment file from the template:

```bash
cp .env.example .env
```

The app reads its configuration from environment variables, or from `.env` if present. `DATABASE_URL` and `SECRET_KEY` are required and the app will not start without them. `.env` is git-ignored and must never be committed.

| Variable | Purpose |
| -------- | ------- |
| `ENVIRONMENT` | `development`, `test` or `production` |
| `DATABASE_URL` | PostgreSQL connection string |
| `SECRET_KEY` | Secret used for signing tokens |

## Run the API

```bash
uvicorn app.main:app --reload
```

The API is available at `http://127.0.0.1:8000`.

## API documentation

FastAPI automatically provides Swagger UI at:

```text
http://127.0.0.1:8000/docs
```

The OpenAPI specification is available at `http://127.0.0.1:8000/openapi.json`.

## Endpoints

| Method | Endpoint         | Description                          |
| ------ | ---------------- | ------------------------------------ |
| GET    | `/`              | Check that the API is running        |
| GET    | `/health`        | Health check for containers and cloud |
| GET    | `/products`      | List products                        |
| GET    | `/products/{id}` | Get one product                      |
| POST   | `/products`      | Create a product                     |
| PUT    | `/products/{id}` | Replace a product                    |
| DELETE | `/products/{id}` | Delete a product                     |

## Testing

```bash
pytest
```

Tests set their own environment variables, so they do not need a `.env` file. They cover successful requests, missing products (404) and invalid input (422).
