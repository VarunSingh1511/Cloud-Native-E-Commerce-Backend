# Cloud-Native E-Commerce Platform

## Week 1: FastAPI REST API

This repository contains the Week 1 foundation of a cloud-native e-commerce backend. It provides a simple REST API for managing products. Product data is intentionally stored in memory for now, so it is lost whenever the application restarts.

## Technology

- Python
- FastAPI
- Pydantic
- Uvicorn
- pytest

## Project structure

```text
app/
├── main.py                 # FastAPI application and root endpoint
├── routers/products.py     # Product REST endpoints and temporary data
└── schemas/product.py      # Pydantic request and response schemas
tests/test_products.py      # Automated API tests
```

`ProductCreate` validates data for new products. `ProductUpdate` validates the complete replacement data sent to `PUT /products/{id}`. `ProductResponse` adds the ID generated by the application to the API response.

## Setup

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it in Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the API

```bash
uvicorn app.main:app --reload
```

The API is available at `http://127.0.0.1:8000`.

## API documentation

FastAPI automatically provides Swagger UI at:

```text
http://127.0.0.1:8000/docs
```

The OpenAPI specification is available at `http://127.0.0.1:8000/openapi.json`.

## Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| GET | `/` | Check that the API is running |
| GET | `/products` | List products |
| GET | `/products/{id}` | Get one product |
| POST | `/products` | Create a product |
| PUT | `/products/{id}` | Replace a product |
| DELETE | `/products/{id}` | Delete a product |

## Testing

```bash
pytest
```

## Current limitation

Week 1 uses **in-memory data** only. It does not use PostgreSQL, SQLAlchemy, authentication, Docker, or cloud services. Database persistence will be introduced in a later week.
